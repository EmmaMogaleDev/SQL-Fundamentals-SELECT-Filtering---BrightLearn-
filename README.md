# SQL Fundamentals: SELECT & Filtering

This repository contains my handwritten work for Exercise 01 of the BrightLearn Basic SQL course.

The exercise is pen-and-paper based. For each of the 10 questions, I had to read a provided employees table, write the correct SQL query by hand, and draw the expected output table — all without running the queries in a database. The point is to build an understanding of how SQL thinks before relying on a tool to execute it.

## What the exercise covers

The exercise uses a single `employees` table with 5 rows and 7 columns — id, first_name, last_name, department, salary, hire_date, and city. All 10 questions are answered using only `SELECT`, `WHERE`, `ORDER BY`, `LIMIT`, `DISTINCT`, and `IN`.

The first four questions focus on selecting and sorting: retrieving all columns, finding unique departments, ordering by salary, and limiting results to the top 3. The remaining six introduce filtering with `WHERE`, using `AND` to combine conditions, `OR` to match either of two values, `!=` to exclude a group, and `IN` as a cleaner shorthand for multiple OR checks.

## What's in this repo

The scanned pages contain my handwritten SQL queries and hand-drawn output tables for all 10 questions, written in pen on lined paper as required by the submission rules.
